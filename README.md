# Посмотри в окно

Учебный проект Яндекс Практикума для просмотра коротких видео из разных городов. Введите название города или выберите время суток, чтобы отфильтровать ролики. Нажмите на карточку, чтобы открыть видео, или на кнопку «Показать еще», чтобы загрузить следующую подборку.

В этом проекте вёрстка по макету Figma дополняет готовую логику на JavaScript. Для раскладки и оформления применены CSS Flexbox, псевдоклассы и псевдоэлементы. Формой и карточками можно пользоваться с клавиатуры.

## Локальный запуск

Откройте `index.html` в актуальной версии Chrome, Firefox или Яндекс Браузера. Устанавливать зависимости и собирать проект не нужно. Для получения карточек и воспроизведения видео требуется подключение к интернету.
